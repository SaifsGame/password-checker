A robust and lightweight tool designed to evaluate password strength, check for common vulnerabilities, and help users create secure credentials.

---

## 🚀 Features

- **Strength Analysis:** Evaluates passwords based on length, complexity, character variety (uppercase, lowercase, numbers, symbols), and entropy.
- **Common Password Detection:** Checks passwords against lists of known breached or frequently guessed passwords.
- **Real-Time Feedback:** Provides instant tips and recommendations to improve weak passwords.
- **Lightweight & Fast:** Built for efficiency with minimal dependencies.
- **Secure & Private:** Performs checks securely (client-side / locally without exposing plaintext credentials).
